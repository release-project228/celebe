celebe

VK pages · analytics · subscribers · engagement · ratings

celebe is a set of analytics tools for public VK pages. It shows how a page's audience changes over time: subscriber dynamics, engagement with posts and how one page compares with another. Everything is built from public page data, so there is no login and no special access required.

The tools answer practical questions for page owners and researchers: is the audience growing or shrinking, which posts get the strongest reaction and which pages in a niche are leading. Instead of collecting numbers by hand over weeks, you get them in one view.

  • Track subscriber growth over time
  • Measure engagement with published posts
  • Compare pages side by side
  • Numbers ready to use in reports

The service is aimed at community admins, SMM specialists and anyone who watches the VK landscape. Pages load quickly, so checking several communities in a row takes seconds rather than an afternoon.

The full product runs at https://celebe.ru.
